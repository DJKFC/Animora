# Animora — студия 2D-анимации для Android

Нативное приложение (Kotlin + Jetpack Compose, без WebView) для покадровой, твин- и костной анимации,
по мотивам Adobe Animate, с упором на планшет и стилус.

## Сборка
1. Установите **Android Studio** (Koala / Ladybug или новее) с Android SDK 34.
2. `File → Open` → папка `Animora`. Студия сама скачает Gradle 8.7 и зависимости
   (если попросит создать Gradle Wrapper — согласитесь, либо выполните `gradle wrapper` в папке проекта).
3. Подключите телефон/планшет (Android 10+) и нажмите **Run ▶**. APK: `Build → Build APK(s)`.

## Стартовая среда
- Список проектов с миниатюрами, переименование, дублирование, удаление, импорт проекта из `.json`.
- **Мастер нового проекта**: название, 12 пресетов разрешения (HD, Full HD, 2K, 4K, Reels/TikTok 9:16,
  квадрат, 4:5, стикер, GIF, раскадровка, пиксель-арт, кино 2.39:1), свой размер с кнопкой «поменять стороны»,
  FPS (8–60), длительность в секундах, фон (цвет / прозрачный / бумага), шаблоны:
  «Покадровая», «Перекладка + кости» (готовый скелет персонажа), «Анимация движения» (пример с мячом), «Пустой».
  Живой предпросмотр холста.

## Редактор
**Рисование**: кисти Перо, Карандаш, Маркер, Аэрограф, Каллиграфия; пиксельный и штриховой ластик;
заливка с допуском, **закрытием зазоров** и заливкой «под линиями»; пипетка; линия (привязка к 15°),
прямоугольник, эллипс (с заливкой); лассо с перемещением/масштабом/поворотом, копировать/вырезать/вставить,
дублировать, отразить, перекрасить выделенное, порядок наложения; симметрия (верт./гор./четверная);
стабилизатор линии; сужение концов. Штрихи векторные — не теряют качество при масштабе.

**Кисти Krita** (импорт: кнопка «+ Кисти Krita» на панели кисти или в окне «Кисти»):
- `.kpp` — пресеты кистей Krita (название, размер, непрозрачность, поток, шаг, угол, нажим → размер/прозрачность,
  поворот по направлению штриха или случайный, разброс);
- `.bundle` — наборы ресурсов Krita целиком (все пресеты + их кончики);
- `.gbr`, `.gih` (анимированные, несколько кончиков), `.png` — кончики кистей.
Кончики `auto_brush` (круг/квадрат, сплющивание, мягкость, лучи) воссоздаются процедурно, текстурные и цветные кончики
поддерживаются. Использованные кисти встраиваются в файл проекта. Ограничения: особые движки Krita
(смешивание цвета, волоски, деформация) упрощаются до штамповой кисти, текстуры холста и кривые датчиков не переносятся,
`.abr` (Photoshop) не поддерживается.

**Стилус**: нажим → толщина/прозрачность с настраиваемой кривой, наклон → ширина (штриховка),
обратный конец пера = ластик, кнопка 1 = ластик, кнопка 2 = пипетка, курсор кисти при наведении,
защита от ладони (режим «только стилус» включается автоматически), низкая задержка ввода.

**Жесты**: щипок — масштаб, два пальца — поворот и сдвиг холста, тап двумя пальцами — отмена, тремя — повтор.

**Таймлайн**: ключевые и пустые ключевые кадры, удержание экспозиции, вставка/удаление кадров
(для всех слоёв или одного), копирование ключей, метки, переход к пред./след. ключу, скраб по шкале,
подсветка секунд, долгое нажатие на ячейку — меню кадра.

**Анимация**: классический **твин движения** (позиция, поворот, масштаб, прозрачность, центр вращения),
**твин формы** (морфинг штрихов), 8 видов сглаживания (разгон, торможение, перелёт, отскок, пружина, ступенька…),
**кости**: создание иерархии, позирование FK и **IK**, ключи поз с интерполяцией, привязка слоёв к костям.

**Слои**: рисования и костей, видимость, блокировка, непрозрачность, 7 режимов наложения, направляющие слои
(не экспортируются), дублирование, слияние, порядок; импорт изображения как референса для ротоскопии.

**Луковая кожа**: число кадров до/после, прозрачность, цветная/обычная, по ключам или по кадрам, для всех слоёв.

**Воспроизведение**: цикл, туда-обратно, один раз; проигрывание диапазона.

**Экспорт** (в «Загрузки/Animora» + «Поделиться»): MP4 (H.264), GIF, PNG-секвенция (ZIP), спрайт-лист,
текущий кадр, файл проекта; масштаб 25–200 %, прозрачный фон, пинг-понг.

Отмена/повтор (80 шагов), автосохранение.

## Новое, чего нет в Animate
- Заливка с закрытием зазоров в контуре и автоматически «под линиями».
- **Запекание твина** в настоящие промежуточные кадры для ручной доработки.
- Разворот анимации слоя во времени и зацикливание слоя N раз.
- Перекраска выделенного одним касанием, каллиграфическое перо, наклон стилуса.
- Калька «только по ключевым рисункам», режимы рисования на пустом кадре (пустой ключ / копия / правка).
- Сетка, правило третей, безопасные зоны, зеркальный просмотр холста.

## Структура
```
model/   — проект, слои, ключи, штрихи, кости; JSON-сериализация и хранилище
engine/  — построение штрихов, рендер кадра, твины/морфинг, кости и IK, заливка, история
export/  — GIF (LZW), MP4 (MediaCodec), PNG/ZIP, спрайт-лист
ui/      — стартовый экран, мастер проекта, редактор (холст, таймлайн, слои, диалоги)
```
